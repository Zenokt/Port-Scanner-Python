# Python Port Scanner

## Description
This is a lightweight, multi-purpose TCP Port Scanner developed to understand the fundamentals of network socket programming and security reconnaissance. As a Computer Engineering student focused on Cyber Security, I built this tool to automate the process of identifying open ports on a target system.

## Features
* Scans common TCP ports (21, 22, 80, 443, etc.).
* Utilizes Python's `socket` library for network communication.
* Fast execution with a defined timeout for responsiveness.
* Clean and easy-to-read console output.

## Technical Skills Applied
* **Language:** Python
* **Networking:** TCP/IP Protocols and Port analysis
* **Tools:** Developed in a Linux environment (Kali Linux)
